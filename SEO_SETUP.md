# SEO launch checklist

The code now prioritizes **Chennai** and communicates booking coverage across **Tamil Nadu**.

Before production launch:

1. Replace placeholder contact details and artist profile information.
2. Replace stock images with the client's approved real portfolio wherever possible.
3. Once the final domain is purchased, add the production canonical URL and `og:url`.
4. Add an `og:image` using a real branded bridal image.
5. Create a production `sitemap.xml` using the real domain.
6. Connect the final domain to Google Search Console after deployment.
7. Keep city content useful and natural. If dedicated Chennai / Coimbatore / Madurai pages are created later, each page should contain genuinely unique local booking information rather than copied text with only the city name changed.

Current primary SEO phrases:
- Bridal Makeup Artist Chennai
- Bridal Makeup Chennai
- Wedding Makeup Artist Chennai
- Bridal Makeup Artist Tamil Nadu
- Wedding Makeup Tamil Nadu
